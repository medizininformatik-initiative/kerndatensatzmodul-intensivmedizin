Abstract base for quantitative nutritional intake observations. Concrete profiles specify nutrient/energy, codes, unit and amount-versus-rate semantics. The identity-code value set is extensible. This base has no fluid-balance codes, fixed category or millilitre constraint. Patient, effective time, coding version and complete quantities are required; either a quantity or dataAbsentReason must be present. Periods require start and end. Performer retains all standard FHIR reference types.
